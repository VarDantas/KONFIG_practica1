#Практическое задание №1. Эмулятор оболочки ОС (Вариант 16)

##Общее описаниеxxанный проект представляет собой эмулятор командной оболочки UNIX-подобной ОС.
Реализован на языке Python. Этап 1: минимальный прототип REPL.

##Функции и настройки
- `get_prompt()` — формирует приглашение вида `username@hostname:~$` на основе реальных данных ОС.
- `parse_input(user_input)` — разбирает ввод на команду и аргументы, раскрывает переменные окружения (`$HOME` и т.п.).
- `execute_command(command, args)` — выполняет команду или выводит ошибку. Команды `ls` и `cd` — заглушки.
- `main()` — главный цикл REPL.
